# DEVFIX

## AI-Powered Coding Error Analyzer

DEVFIX is an AI-powered web application that helps students and developers understand programming errors and find possible solutions.

### Features

- AI-powered error analysis
- Beginner-friendly explanations
- Error severity
- Reason behind the error
- Suggested fixes
- Corrected code examples
- Supports multiple programming languages

### Supported Languages

- C
- C++
- Java
- Python
- JavaScript
- HTML
- CSS
- SQL

### Tech Stack

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express.js
- OpenAI API
